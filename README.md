# حاسبة صبغات المسبغة — Android

نسخة أولى قابلة للتطوير. التطبيق:
- يضيف تركيبة لكل كود.
- كل كمية مخزنة كأساس جم لكل 100 كجم.
- يحسب الكمية تلقائياً لأي وزن حوض.
- يحفظ التركيبات على الجهاز.
- يسمح بالتعديل وإضافة صبغات متعددة.

مثال الكود 557:
بيج = 150 جم
بني محروق = 50 جم
أصفر GL = 3.8 جم

الحساب: الكمية = كمية الأساس × وزن الحوض ÷ 100.

لإنشاء APK:
1. افتح المجلد في Android Studio.
2. اختر Build > Build APK(s).
3. ستجد APK داخل app/build/outputs/apk/debug/.

ملاحظة: هذه نسخة أولى بدون مزامنة سحابية، والبيانات محفوظة محلياً على الموبايل.
